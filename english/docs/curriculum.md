# English in Use：课程与练习范围

这套内容面向已经能够阅读、写作和交流，希望恢复主动使用能力、提高表达质量的中文学习者。重点是把意思说准确、选对语气、组织清楚、参与讨论，以及讲述真实经历。

课程不以考试刷题为主，也不把完成课数、选择题正确率或练习时长换算成 CEFR 等级、母语身份或“接近母语”的保证。不同学习者的听力、发音、词汇、互动和写作能力可能差异很大，实际目标应结合各自的使用场景来判断。

## 当前内容

| 轨道 | 练习重点 | 课数 |
| --- | --- | ---: |
| precision · 表达精确 | 证据与推断、范围、动词、承诺边界 | 4 |
| register · 语气与场合 | 可执行的邮件、轻松聊天、坚定反馈、关系变化 | 4 |

共 24 课，每课有一组带语境说明的 before/after、3 道选择题、1 个开放迁移任务和 3 个表达块。全库共 72 道课程题、72 个表达块，另有 8 道基线题。

例句和情境均为原创、虚构的通用练习，不摘录任何个人工作材料、私人研究、真实邮件或学习成绩。将练习迁移到真实生活时，应换成自己确实知道的事实与经历。

## 一课怎样练

### 1. 判断：弄清为何在这里这样说

先读情境和 before/after。before 不一定有语法错误，after 也不是任何场合下都更好。要能说出它改变了什么：范围更准确、请求更具体、指代更明确、语气更合适，或更容易让听者跟上。

选择题给定具体目的和已知事实，在这些约束下选择一个最可辩护的选项。其他选项可能是语法成立的英语，也可能适合不同语境。解释应关注它为什么不符合当前任务，而不是把表达差异一律称为错误。

### 2. 回忆：先尝试，再看表达

表达块的 `prompt` 给出要完成的交际功能。先遮住原句，自己说一种实现同样功能的表达，再看示例。没有逐字复现也可能成功；关键是意思、范围和语气是否匹配。

例如想说明证据支持一种解释但未证明它，可以回忆 “That is consistent with …”，也可以用其他准确的句式。表达块提供可取用的起点，不是必须背诵的唯一台词。

### 3. 迁移：换内容、换听者、换时间限制

完成开放任务时，先不看 model。自己写或说一遍，再按任务清单检查，最后才对照示例。model 展示一种可行做法，不应作为逐字匹配答案或自动评分标准。

同一项技能至少换一次语境。例如，把工作中的交付澄清迁移到朋友约时间；把会议里的分歧表达迁移到阅读讨论；把一段一分钟故事压缩成二十秒版本。迁移时保持事实不变，调整信息选择和语气。

### 4. 自评：看完成了什么，不只看像不像范文

每课的 checklist 提供具体问题。一次练习后选择一个最值得修改的点，再做第二遍，避免把每个词都改到没有自己的声音。

| 检查面向 | 可以问自己的问题 |
| --- | --- |
| 意思 | 听者会理解成我真正想表达的内容吗？ |
| 范围 | 我有没有把可能说成确定、把部分说成全部？ |
| 场合 | 这像对当前这个人说的话吗？ |
| 结构 | 对方能找到重点、跟上指代和关系吗？ |
| 互动 | 这句话是否帮助下一轮交流，而非只完成我的独白？ |
| 真实 | 我有没有为表达顺畅编造事实、动机或经历？ |

之后在新的话题里再用一次。熟悉旧题后的高正确率主要反映对旧材料的掌握；未经准备的新表达任务更能帮助发现迁移上的困难。

## 基线诊断如何解释

8 道基线题只用于观察当前在这些具体题目中的判断表现，并提供练习起点。题量不足以全面测量任何轨道，更不能认证英语水平或推断口语、听力和发音表现。

答对选择题说明能在给定选项中识别合适表达，不等于能在没有提示时迅速说出来。答错也可能源自没有读清情境，不能直接判断成“不具备某项能力”。建议记录错误原因，再用开放任务验证。

不从基线分数生成 CEFR、考试分数或母语程度结论。重复做同一套题时，应知道自己已经见过内容。

## 语言选择与内容原则

- **多个表达可以成立。** 正式与随意、长与短、主动与被动各有用途；课程只在具体语境里说明取舍。
- **不以虚假语病制造练习。** 选择题的重点是含义、信息范围和语用匹配，避免把明显不成句的选项当作高级练习。
- **不强制单一英语口音或地域习惯。** 当前内容以广泛可理解的表达为主；合理的地区差异不应当作错误。
- **不把公司套话当成高级表达。** 精确的普通词通常已经足够。较正式词语在真正需要时仍可使用。
- **不把某种表达变成固定人格。** 坚定、谦逊、温暖或简洁都应服务当前目的；无需每一句都加缓和语或每一轮都用同样的衔接句。

## 当前版本的局限

这些原创活动没有经过标准化难度校准、真实学习者实验或真人语言教师逐题审定。题库规模适合起步与反复迁移，不等于完整的高级英语课程。

当前课程素材侧重措辞、结构、语气和互动策略。它不能独立证明发音、自然语速听力、地域变体理解、实时反应或复杂专业表达已经达到某种水平。若应用提供录音或示范发音，其价值是便于回听和对照，不应被描述为真人评审或客观口语评分。

持续改进应结合真实交流中的理解情况、对方的反馈、未经准备的表达样本，以及不同场景中的表现。可以追求更自然、更灵活、更准确的实际英语，但这里不承诺某个期限内达到“母语水平”。
