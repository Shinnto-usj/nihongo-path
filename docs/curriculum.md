# Nihongo Path：学习内容与验收说明

适用对象：以中文学习日语、从零基础起步、希望在日本生活中使用日语的成人。

**目标日期由学习者自行设置。** 系统按首次创建计划日到个人目标日的比例安排复盘；比例只是日程分配，不代表达到某等级所需时长，也不预测学习能力或达标概率。最后一次检查使用个人设置的目标日，不是正式 JLPT 考试日期。学习者也可填写城市、出发日和每日可投入时间。课程中的リナ（莉奈）是虚构示例姓名。

## 当前版本包含什么

`content/course.js` 提供 24 节原创微课、120 道原创练习题、8 个分支生活场景、9 个官方学习与测评入口，以及 6 个按个人计划比例计算日期的能力检查点。每课有目标、解释、例句、词卡、选择题/输入题/听力题与逐题说明。

| 阶段 | 微课数量 | 本版本的作用 |
| --- | ---: | --- |
| foundation | 6 | 从元音与假名进入发音、常用词和交流修复 |
| N5 | 6 | 自我介绍、点单、问路、时间、日常活动、喜好 |
| N4 | 4 | 请求与许可、经历与能力变化、原因与条件、报修 |
| N3 | 3 | 传闻与推测、生活通知、最终安排；导入样例 |
| N2 | 3 | 让步与限定、文章主张、委婉表达；导入样例 |
| N1 | 2 | 抽象论证、隐含意图与综合理解；导入样例 |

场景包括咖啡馆、便利店、问路、酒店入住、住宅报修、诊所沟通、市政窗口和邻里交流。部分场景允许两种正确回应，错误回应提供解释并返回当前节点。重要信息通过复述来确认。

**这些内容是可开始练习的基础与示例库，不是完整的 N5—N1 课程、完整题库、标准化水平测试或语音评分系统。** 课程标签仅表示建议的学习阶段，原创题目没有经过 JLPT 等值校准。部分场景包含超出该级别的真实礼貌表达，应用应保留假名、中文提示与重复播放。

## 两条学习线

### 日本生活线

从“能完成一件事情”出发：买到需要的东西、听懂方向、确认约定、说明房间故障、在没有听懂时继续沟通。每天既练听懂，也练自己说出来。不要因为能看懂日文汉字就跳过读音和听力。

国际交流基金会的 IRODORI 面向日本生活与工作中的基本交流，并提供自学课程与音频。它适合作为生活线的系统材料。官方说明也提醒，IRODORI 并非专为 JLPT 应试而设计，准备考试还应练习官方题型和练习册。

来源：[IRODORI FAQ](https://www.irodori.jpf.go.jp/en/faq.html)、[IRODORI 在线课程](https://www.irodori-online.jpf.go.jp/)、[中文版入口](https://www2.jpfbj.cn/irodori/)。

### N1 能力线

JLPT 的等级描述围绕语言知识、阅读和听力展开。N1 的方向包括复杂或抽象文字的结构与内容、作者意图，以及多种场景下自然语速材料中的逻辑、关系和要点。因此，词卡数量或连续打卡不能独自证明达到 N1。

每周应同时检查：对未见过材料的理解、错误原因、听力是否依赖字幕，以及阅读速度与准确性之间的关系。生活口语另行练习、另行验收。

来源：[JLPT 各等级能力描述](https://www.jlpt.jp/e/about/levelsummary.html)、[考试特点](https://www.jlpt.jp/e/about/points.html)。

## 如何使用每日时间

每日分钟数是用户可调整的计划参数，而不是达到 N1 所需时数的官方估算。通用默认日预算为 30 分钟，用于建立起步练习节奏，不表示每天 30 分钟足以达到 N1。任务安排应覆盖复习、新课、真人听力、阅读和开口，不把全部时间耗在卡片上。

一个可调整的 180 分钟示例：

| 部分 | 分钟 | 具体动作 |
| --- | ---: | --- |
| 到期复习 | 25 | 先回忆再翻面；按真实记忆状态评分 |
| 系统课程 | 45 | 新语法、词汇与基础汉字；做配套练习 |
| 听力与跟读 | 40 | 真人音频先听后看，复听并录音对照 |
| 阅读 | 40 | 从短句到文章，写出主旨和依据 |
| 生活表达 | 20 | 场景对话、复述、现实交流或口语课 |
| 复盘 | 10 | 记一个错误原因和明天要验证的点 |

这只是任务拆分示例，不是 180 分钟足以在截止前达到 N1 的断言。没有时间承诺、完整课程和持续测评，不能对结果作可靠保证。遇到持续疲劳或正确率下降，应调整新内容量，而不是把未学内容标为已掌握。

## 检查点如何解释

| 个人计划跨度的位置 | 检查重点 |
| --- | --- |
| 6% | 假名、拍子、长短音，能请求重复和慢说 |
| 17% | 基本句子、慢速短对话、生活任务；N5方向检查 |
| 31% | 基础阅读和日常说明，能描述问题；N4方向检查 |
| 52% | 条件、例外、最终安排；N3方向检查 |
| 79% | 文章观点、自然表达、委婉意图；N2方向检查 |
| 100%（个人目标日） | 复杂阅读、自然语速综合听力；N1目标检验 |

这些比例只决定何时提醒复盘，不决定学习速度、所需总时长或等级达成时间。它们不是预测和自动升级规则；调整目标日后，检查日期按相同的个人计划跨度比例重新计算。如果某阶段明显落后，要根据实际分项能力决定延长基础学习、增加投入或调整目标，不把日历翻页当作等级提升。

## 测评记录与边界

练习记录应区分：

1. **首次练习表现**：没有看答案、没有提前看听力原文的结果。
2. **复习表现**：见过的题是否再次答对，用于记忆与错因检查。
3. **外部完整练习**：来源、等级、用时、是否首次接触、是否暂停、各分项原始正确数。
4. **正式成绩**：仅在确有成绩单时录入；不得由应用正确率自动推算。

JLPT 官方样例页每个题型只给出少量例题，主要帮助认识题型。官方练习册提供更完整的练习入口。正式 JLPT 得分采用量尺分并设分项要求，原始正确率不是相同的数值体系。本应用不生成“通过概率”或宣称自制小测等于官方分数。

来源：[官方题型样例](https://www.jlpt.jp/e/samples/forlearners.html)、[官方练习册](https://www.jlpt.jp/e/samples/sampleindex.html)、[分项与合格判定](https://www.jlpt.jp/e/guideline/results.html)。

## 内容与语音质量说明

所有内置题目、例句、场景均为本项目原创，不复制官方试题或整套教材。官方资源仅提供链接。生成语音适合重复练习，但声音质量、可用性和日语读音受浏览器及设备影响。必须保留真人音频入口，不能以合成语音训练覆盖正式听力要求。

罗马字只作为初学辅助。N3 及以上样例不提供罗马字，阅读应逐步减少对它的依赖。输入题只检查预设答案；同义但未列入的回答可能无法判对，应结合解释复核。

诊所与市政窗口场景仅训练语言，不提供医疗诊断、治疗、法律规定或具体行政期限。场景中询问材料、确认说明的表达可以复用，实际要求由相应机构确认。

本版本已做结构与答案自查；未经真人日语教师逐题审校，也未进行标准化难度标定。后续最有价值的内容改进应来自学习者真实错误、真人交流反馈与阶段测评，而不是只增加名义上的课数。
